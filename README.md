# 能量乱斗（Energy Brawl）

局域网横屏多人对战小游戏。Windows 电脑运行权威服务器，手机或电脑浏览器通过同一局域网加入；最多 6 名玩家，不足席位由 AI 补齐。

当前版本：**v4.2.0**

## v4.2.0 据点争夺与团队玩法

- 3v3 与 2v2v2 新增中央据点：进入据点可推进占领进度，敌我同时存在时进入争夺并暂停推进。
- 占领据点后持续获得团队据点分，达到 100 分由服务器判定团队获胜；个人战规则保持不变。
- 移动端新增紧凑团队分数、据点状态和争夺提示；Phaser 场景显示据点环形进度、队伍颜色和争夺脉冲。
- 团队 AI 会优先抢占或支援据点，低血量时仍会撤退，避免完美集火。

## 功能概览

- 6 人横屏 LAN 对战，空位自动由普通难度 AI 补齐。
- 服务器权威模拟：移动、碰撞、射击、伤害、击杀、复活和计分在服务器计算。
- 六名具有不同数值取舍和被动特性的角色，可在每局开始前重新选择。
- 普通能量球与技能球收集、技能槽和右侧移动攻击操作。
- 子弹按距离限制生命周期，服务器进行墙体截断和碰撞判定，避免穿墙命中。
- 脱战快速回血、复活护盾、全场击杀播报和连杀音效。
- 电脑房主控制台：扫码地址、房间状态、玩家管理和受保护的房主命令。

## 对局规则

- 最长对局时间：8 分钟。
- 目标分数：20 分。
- 普通击败奖励 2 分；击败当前占领者额外奖励 1 分；收集能量球奖励 1 分。
- 达到目标分后进入 30 秒占领倒计时；时间结束时领先者获胜，同分进入加时。
- 结算后可以返回大厅，超时也会自动返回。

## 环境要求

- Windows、macOS 或 Linux
- Node.js **22 或更高版本**（建议使用当前 LTS）
- 同一局域网内可互相访问的手机/电脑浏览器

## 安装与启动

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run server
```

服务器启动后会在终端打印房主控制台地址、手机加入地址和二维码。Windows 用户也可以双击根目录的 `启动游戏.bat`，脚本会检查 Node.js、安装依赖、构建客户端并启动服务器。

开发模式：

```powershell
npm.cmd run dev
```

## 手机加入局域网对局

1. 电脑和手机连接同一个 Wi-Fi；不要使用访客网络。
2. 运行服务器，在电脑终端找到 `手机加入` 地址或扫描二维码。
3. 手机保持横屏打开地址，首次触摸页面以启用浏览器音频。
4. 左半屏任意位置按下生成移动摇杆，右半屏任意位置生成瞄准/射击摇杆；页面已禁止缩放和滚动。

如果手机打不开页面：关闭路由器的客户端/AP 隔离，允许 Node.js 通过 Windows“专用网络”防火墙，并暂时关闭手机移动数据。

## 房主控制台安全说明

服务器启动时会随机生成房主令牌，并只打印在服务器终端的本机控制台地址中。房主命令只接受回环地址（`localhost`/`127.0.0.1`）和匹配令牌；不要把带有 `token` 的房主 URL 发布到 GitHub、截图或聊天群。生产部署时请使用 HTTPS、反向代理和独立的访问控制，不要把开发服务器直接暴露到公网。

## 目录说明

```text
src/client/       Phaser 客户端、移动端 UI、音频和视觉反馈
src/server/       房间、固定步长模拟、网络和房主控制台
src/shared/       协议、常量、角色与技能目录
public/assets/v3/ 全部正式运行时素材及完整素材清单（上传时必须整体保留）
scripts/          素材导入、音效处理和压力测试脚本
tests/            单元、网络、资产和模拟测试
docs/             历史设计/实施文档
```

`public/assets/v3/` 是唯一运行时素材根目录，包含角色、八方向图、武器、地图、能量球、技能图标、子弹特效、连杀音效和 `manifest.json`。上传 GitHub 时应完整提交该目录。`dist/`、`node_modules/`、`coverage/` 和 `artifacts/` 是本地产物，已加入 `.gitignore`，不应提交。
