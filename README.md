# 能量乱斗（Energy Brawl）

局域网横屏多人对战小游戏。Windows 电脑运行权威服务器，手机或电脑浏览器通过同一局域网加入；最多 6 名玩家，不足席位由 AI 补齐。

当前版本：**v4.9.1**

## v4.9.1 稳定性与视觉收尾
- 服务端新增内存房间目录：六位房间码、房间列表、按码加入和快速加入；不同房间的房间状态、快照、输入、队伍信号、房主命令和逐房间模拟互相隔离。
- 断线重连请求会携带房间码与令牌；对局中断线继续由 AI 接管，重连后恢复原玩家实体与控制权；主动切换房间会立即释放大厅席位。
- 手机大厅新增创建房间、快速加入、房间码输入和可点击房间列表，房间码保存到本机并用于后续重连。
- 房主开始按钮进入可取消的 5 秒准备倒计时；倒计时期间任一真人取消准备或离开都会回到大厅。赛后保留真人席位进入重新选角，保留玩家重新准备后由房主再次开始下一局倒计时。
- 新增生命周期快照字段与移动端倒计时提示，保留旧 `GameRoom.startMatch()` 直接调用兼容性。
- 战斗实体新增非颜色队友识别：队友显示菱形标记、朝向提示和加粗队伍环；敌方使用独立尖角标记；AI 接管显示独立 `AI` 徽标，死亡/复活状态同步隐藏与恢复。
- 手机大厅参战席位新增红/蓝/金/个人形状标记，并将机器人状态明确显示为“AI 接管”，不依赖颜色或文字单一提示。
- 本轮门禁：全量 Vitest 131 个测试文件、715 项测试通过；类型检查和生产构建通过；3 张地图 × 6 模式 × 临时事件开关的六人压力模拟通过（墙体违规 0、过期状态残留 0、服务端步进 P95 小于 0.1ms）；双房间六客户端隔离与断线接管回归通过；桌面与 844×390 手机横屏视觉检查通过。

- 赛后新增逐回合胜负、结束原因和存活情况，并保留击杀、治疗、承伤、技能贡献、地图机制贡献与 MVP 数据。回合结果只显示单条清晰播报。
- 动态地图事件在团队歼灭模式中每回合最多触发一次；回合重置清理危险区、增益、事件视觉和输入/技能队列。客户端事件去重键包含 `round:eventSeq`，避免跨回合误判旧事件。
- 死亡观战期间旧子弹不会继续触发本地攻击音效；机器人仍只选择敌方目标。完整 DPR、粒子、拖尾、技能特效、音效和震动策略保持不变。
- 团队歼灭 HUD 会隐藏普通模式的全局计时器和据点分数条，避免回合 HUD 与旧模式信息重叠；房主将生命值改为 `0` 时走权威死亡流程，支持观战和回合判定。
- 回合结算展示窗口延长至 4 秒，保证桌面、iPhone 横屏和 iPad 横屏都能稳定看到单条结算播报；下一回合恢复生命、出生点和镜头状态。

## v4.6.0 六角色专属特效、子弹表现与环境音

- 六名既有角色全部补齐“指示、施放、生效、结束”四阶段专属技能反馈；位移、治疗、壁垒、过载、相位与残像均使用独立形状、配色、粒子节奏和对象池，不新增角色，也不改变 v4.5.0 的战斗平衡。
- **烈锋 · 破阵突进**：加入路径指示、锚点建立、连续位移残影和返回过程；主动返回使用锚点坍缩，超时结束使用锚点消散，二者拥有不同收尾反馈。
- **脉冲医师 · 脉冲急救**：加入治疗范围、扩散脉冲、对每个受治疗目标的能量流，以及净化压制时的独立闪光反馈。
- **堡垒 · 移动壁垒**：加入正面弧形指示、壁垒展开、友军保护辉光、敌方射速压制和护盾接触反馈，方向始终跟随服务器权威朝向。
- **电弧枪手 · 电容过载**：加入武器充能、持续电流、强化枪口和安全放电；强度根据服务器技能剩余时间变化，武器特效继续位于人物图层上方。
- **相位狙手 · 相位折跃**：加入独立位移走廊、起点空间撕裂、穿梭路径、终点像素重组和裂隙闭合，不与普通射击指示器共用。
- **疾行者 · 残像疾奔**：加入加速爆发、固定对象池方向残像、强化子弹尾焰和残像回收合并，效果数量不随设备性能或帧率降级。
- 技能事件由服务器发布有界、递增序号的权威生命周期记录；客户端按序去重并在重连时只重建持续状态，不会重播历史施放音效。
- 技能生命周期只通过快照中的权威事件数组传递；拒绝的技能请求不产生事件，死亡、超时、返回和强制重置各自只发布一次结束事件，避免重复播放和残留特效。
- 所有技能效果使用固定容量对象池；位移路径和子弹拖尾按世界距离采样，不依赖本地帧数，桌面、iPhone 和平板保持相同长度与密度。
- 六套技能分别拥有施放、生效、结束音色和震动节奏，并提供可解码样本与程序合成后备；距离衰减、并发上限和优先级由统一音频总线控制。
- 六名角色拥有独立的枪口、弹芯、世界距离拖尾、墙体命中、玩家命中与护盾命中特效；命中位置和类型由服务器扫掠碰撞结果决定，不再通过“子弹消失”猜测，也不允许穿墙。
- 客户端首次收到快照时只建立事件序号基线，后续按序播放新的技能与命中事件；断线重连不会补播旧枪声、旧命中或旧技能阶段。
- 三张地图加入独立循环环境音。地图机制预警和生效期间会压低环境音与远端枪声，本地击杀、受击和专属技能仍保持高优先级。

## v4.3.2 房主性能诊断

- 房主控制台新增默认折叠的实时性能诊断区，显示六名真人玩家的 RTT、操作确认延迟 P95、最长帧间隔、位置校正、重连情况，以及服务端步进和追帧上限触发次数；玩家页面和战斗 HUD 不显示诊断信息。
- 固定告警阈值为：RTT `> 120ms`、操作确认延迟 P95 `> 100ms`、位置校正 `> 30px`、帧间隔 `> 50ms`、服务端步进 `> 16ms`，以及断线或重连事件。
- 浏览器每秒只发送一个聚合样本，并使用独立的低优先级 volatile 通道；诊断不会降低画质、特效、DPR、输入频率或 30Hz 快照频率。
- 房主浏览器保存最近 10 局报告并支持 JSON 导出。报告只使用 `P1`–`P6` 匿名编号，IPv4 显示为 `192.168.1.xxx` 形式，不包含昵称、房主令牌或原始 IP。
- 设备信息只使用浏览器主动提供的浏览器、平台、网络能力和型号字段；浏览器未提供具体型号时显示“未知型号”，不会根据屏幕尺寸猜测 iPhone 或其他设备型号。
- 使用 `npm.cmd run load-test:diagnostics` 可运行六客户端、每秒一包、60 秒的真实 Socket.IO 诊断压力门，并验证超频/超大载荷拒绝、六客户端不断线和端到端聚合 P95 `< 5ms`。

## 功能概览

- 6 人横屏 LAN 对战，空位自动由普通难度 AI 补齐。
- 服务器权威模拟：移动、碰撞、射击、伤害、击杀、复活和计分在服务器计算。
- 六名具有不同数值取舍和被动特性的角色，可在每局开始前重新选择。
- 普通能量球与技能球收集、技能槽和右侧移动攻击操作。
- 子弹按距离限制生命周期，服务器进行墙体截断和碰撞判定，避免穿墙命中。
- 脱战快速回血、复活护盾、全场击杀播报和连杀音效。
- 电脑房主控制台：扫码地址、房间状态、玩家管理和受保护的房主命令。

## 对局规则

- 最长对局时间：8 分钟。
- 目标分数：20 分。
- 普通击败奖励 2 分；击败当前占领者额外奖励 1 分；收集能量球奖励 1 分。
- 达到目标分后进入 30 秒占领倒计时；时间结束时领先者获胜，同分进入加时。
- 结算后可以返回大厅，超时也会自动返回。

## 手机加入局域网对局

1. 电脑和手机连接同一个允许设备互访的 Wi-Fi/局域网；电脑可使用有线网络，手机使用同一路由器的 Wi-Fi；不要使用访客网络。
2. 运行服务器，打开终端打印的房主控制台地址并扫描其中的二维码。
3. 手机保持横屏打开地址，首次触摸页面以启用浏览器音频。
4. 左半屏任意位置按下生成移动摇杆，右半屏任意位置生成瞄准/射击摇杆；页面已禁止缩放和滚动。

如果手机打不开页面：先运行 `npm.cmd run doctor`，确认二维码对应当前活动网卡并执行防火墙脚本；如果电脑可打开该地址而手机仍打不开，再关闭路由器的访客网络、客户端隔离或 AP 隔离。这些路由器限制无法由本机程序绕过。移动数据、异地公网和跨 NAT 不属于本地版支持范围。

## 房主控制台安全说明

服务器启动时会随机生成房主令牌，并只打印在服务器终端的本机控制台地址中。房主命令只接受回环地址（`localhost`/`127.0.0.1`）和匹配令牌；不要把带有 `token` 的房主 URL 发布到 GitHub、截图或聊天群。生产部署时请使用 HTTPS、反向代理和独立的访问控制，不要把开发服务器直接暴露到公网。
