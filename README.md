# 能量乱斗

局域网手机横屏六人竞技游戏。Windows 电脑运行权威服务器，手机浏览器扫码加入，真人不足时由 AI 补齐。

## 环境要求

- Windows 10 或 Windows 11
- Node.js 22 或更高版本
- 一台支持 5 GHz 或 6 GHz Wi-Fi 的路由器
- 主机电脑和手机连接同一个局域网

RTX 显卡不是必需条件。服务器主要使用少量 CPU 和内存，普通现代电脑也能运行六人对局。

## 启动

双击项目根目录中的 `启动游戏.bat`。

首次启动会安装依赖并构建网页，随后启动服务器并打开主机控制台。主机控制台显示手机加入地址和二维码。

Windows 第一次询问防火墙权限时，只需允许“专用网络”。不要开放公用网络权限。

## 开局流程

1. 手机扫描主机控制台中的二维码。
2. 手机横屏，输入昵称并选择未占用的颜色。
3. 玩家点击“准备”。
4. 主机点击“开始对局”，空位自动补充 AI。
5. 对局结束后，主机点击“重置”返回大厅。

## 操作

- 左摇杆：移动
- 右摇杆：瞄准并连续射击
- 收集能量球：加 1 分
- 击败对手：加 3 分
- 率先达到 15 分：获胜

## 局域网排障

如果手机无法打开加入地址：

1. 确认手机和电脑连接同一个 Wi-Fi，且手机没有使用访客网络。
2. 在路由器中关闭“客户端隔离”“AP 隔离”或“无线隔离”。
3. 确认 Windows 防火墙允许 Node.js 访问专用网络。
4. 优先让电脑通过网线连接路由器，手机使用 5 GHz 或 6 GHz Wi-Fi。
5. 暂时关闭手机移动数据，避免浏览器绕过局域网。

## 开发命令

```powershell
npm.cmd install
npm.cmd run dev
```

生产验证：

```powershell
npm.cmd test -- --run
npm.cmd run typecheck
npm.cmd run build
npm.cmd run server
```

按 `Ctrl+C` 停止服务器。
