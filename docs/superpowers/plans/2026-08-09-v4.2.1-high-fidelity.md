# v4.2.1 High-Fidelity Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep every client on full visual quality and full snapshot cadence while improving canvas sharpness and retaining smooth six-player combat.

**Architecture:** Remove the automatic reduced-performance mode rather than allowing frame-time spikes to alter the visual contract. Rendering remains fixed at high quality, requests the browser's high-performance GPU path, and keeps the existing pooled Phaser objects to avoid per-effect allocation. Network clients keep the full 30 Hz snapshot cadence; no gameplay client may request a reduced mode.

**Tech Stack:** TypeScript, Phaser 3, Socket.IO, Vitest, Vite.
