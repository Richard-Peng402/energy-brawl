# v4.2 据点争夺与团队玩法 Implementation Plan

> **For agentic workers:** Execute task-by-task with test-first checkpoints.

**Goal:** Add a server-authoritative central capture point to every team mode, with team HUD, capture feedback, mobile-safe presentation, balanced bots, and a complete v4.2 release update.

**Architecture:** Keep capture rules in the deterministic server simulation and expose only immutable capture snapshots through the existing protocol. Phaser renders the point and transient state; DOM HUD renders compact team scores/objective text without covering the playfield. Solo mode remains unchanged except for shared capture data being absent.

**Tech Stack:** TypeScript, Vitest, Phaser 3, Vite, Socket.IO.
